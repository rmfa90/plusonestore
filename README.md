# Plus One Store
Kedai dalam talian pakaian muslimah moden. Labuh, longgar, jubah, kurung, batik, hijab &amp; plus size.

## Struktur folder
- `index.html` — laman utama
- `shop.html` — e-commerce shop (filtar &amp; carian)
- `product.html` — butiran produk
- `cart.html` — beli cart
- `checkout.html` — penyelesaian pesanan
- `about.html` / `contact.html` — tentatan &amp; hubungi
- `css/style.css` — nilai warna &amp; responsif
- `js/products.js` — katalog produk
- `js/main.js` — interaksi umum (filter, galeri, langkah)
- `js/cart.js` — enjin beli cart (localStorage)
- `images/placeholders/` — gambar muatna (gantikan dengan gambar sebenar)

## Cara menjalankan
1. Salin keseluruhan folder ke akar repositori GitHub Pages.
2. Tindih ke repositori GitHub Pages (`plusonestore-my.pages.dev`).
3. Selesaikan semua halaman. Gunakan gamepad/teknikal untuk memuatkan.

## Gantikan produk
- Edit `js/products.js` untuk menambah/mengubah produk.
- Ganti SVG dalam `images/placeholders/` dengan gambar pakaian sebenar.

## Rujukan
Struktur kategori &amp; reticulum dibuat merujuk kepada muslimahclothing.com (MCC Lifestyle) untuk menyelaraskan rancangan ekosistem.
